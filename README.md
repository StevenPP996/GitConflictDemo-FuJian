# GitConflictDemo-Student1

COMPX Practical 4 collaboration project.

- `main`: initial Android application with two buttons using the same default colour.
- `feature-red-button`: Student 1 changes both buttons to red.
- `feature-green-button`: to be created by Student 2 from the original `main` commit.

The red branch must be merged first. The green branch is then merged to intentionally produce and resolve an XML merge conflict.
